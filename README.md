# Iris Flower Dataset - Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the famous Iris Flower Dataset using Python.

The main objective of this project is to understand:
- Feature distributions
- Relationships between features
- Species separability
- Statistical properties of the dataset

The dataset contains three flower species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

---

# Libraries Used

- NumPy
- Pandas
- Matplotlib
- Seaborn

---

# EDA Techniques Used

## Univariate Analysis
- Histograms
- PDF (Probability Density Function)
- CDF (Cumulative Distribution Function)
- Box Plots
- Violin Plots

## Bivariate Analysis
- Scatter Plots
- Pair Plots
- Joint Plots

## Statistical Measures
- Mean
- Median
- Standard Deviation
- Percentiles

---

# Key Observations

- Petal length and petal width are useful for species classification.
- Iris-setosa is easily separable from the other species.
- Some overlap exists between Iris-versicolor and Iris-virginica.
- Pair plots and scatter plots help visualize feature relationships effectively.

---

# Conclusion

EDA helps in understanding the dataset before applying Machine Learning models.

This analysis provides insights into:
- Data distribution
- Feature importance
- Class separability
- Presence of outliers
